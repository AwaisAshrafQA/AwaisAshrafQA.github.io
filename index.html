About

Quality from first test plan to release sign-off

I'm an AI-adaptive SQA engineer with seven years in enterprise web, mobile and API quality, most recently on fleet management SaaS at Motive, a platform serving nearly 100,000 businesses.

Claude Code, GitHub Copilot, ChatGPT and Cursor are everyday engineering tools for me. I build custom Claude Code skills and AI agents that automate API testing, weekly releases, test data generation and bug triage. One example is an HOS Analyzer skill that produces Hours of Service test data in minutes instead of days.

Underneath that is a solid automation base (RestAssured, Playwright, Cypress, Selenium, Appium) and QA leadership across test strategy, regression suites and release sign-off.
