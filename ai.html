2Domain Skill

HOS Analyzer: Compliance Test Data in Minutes

The Problem
Testing ELD and Hours of Service (HOS) features for FMCSA compliance requires realistic driver-log data, which took days to build by hand.
What I Built
A production HOS Analyzer that encodes FMCSA ELD/HOS compliance rules to generate realistic test data on demand. Alongside it, I built skills that trace UI and backend issues to root cause and propose fixes for developer review.
The Result
HOS test data creation dropped from days to minutes, and developers received root-cause analysis and proposed fixes to review, shortening their turnaround.

3AI Agents

AI Agents for Defect Triage and Regression Analysis

The Problem
Working out why tests failed meant digging through logs and writing up defects by hand, every sprint.
What I Built
I designed, built and ran in production LLM-based QA agents using LangChain and OpenAI APIs for test data generation, defect triage and regression analysis, and integrated them with Datadog, Splunk and Jira to analyse logs and draft defect reports automatically.
The Result
Triage time dropped by about 40% per sprint.
Triage Flow
1Failed test run and logs (Datadog, Splunk)
2Agent suggests a likely cause
3Agent drafts the Jira defect report
4I verify before it's filed
~40%less triage time per sprint
