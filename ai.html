2Domain skill

HOS Analyzer: compliance test data in minutes

The problem
Testing ELD and Hours of Service (HOS) features for FMCSA compliance requires realistic driver-log data, which took days to build by hand.
What I built
An HOS Analyzer skill for Claude Code that generates HOS test data on demand. Alongside it, I built diagnostic skills that propose fixes for UI and backend defects.
The result
HOS test data creation dropped from days to minutes, and developers received proposed fixes for UI and backend defects, shortening their turnaround.

3AI agents

AI agents for defect triage and regression analysis

The problem
Working out why tests failed meant digging through logs and writing up defects by hand, every sprint.
What I built
LLM-based QA agents using LangChain and OpenAI APIs for test data generation, defect triage, regression analysis and Datadog and Splunk log review, and they auto-drafted Jira defect reports.
The result
Triage time dropped by about 40% per sprint.
Triage flow
1Failed test run and logs (Datadog, Splunk)
2Agent suggests a likely cause
3Agent drafts the Jira defect report
4I verify before it's filed
